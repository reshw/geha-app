# 영업용 데모 스페이스 가이드

## 개요

영업/마케팅 목적으로 사용할 수 있는 데모 스페이스를 제공합니다.
조인 링크를 통해 접근하면 **자동으로 부매니저 권한**을 받아 모든 기능을 체험할 수 있습니다.

---

## 🎯 특징

- ✅ **자동 권한 부여**: 조인 시 자동으로 부매니저(vice-manager) 권한
- ✅ **풍부한 샘플 데이터**: 예약, 정산, 사용자 등 실제 데이터 포함
- ✅ **즉시 체험 가능**: 별도 승인 없이 바로 사용 가능
- ✅ **반복 생성 가능**: 스크립트로 언제든지 재생성 가능

## 🚀 사용 방법

### 1단계: 데모 스페이스 생성

```bash
# 프로젝트 루트에서 실행
node scripts/createDemoSpace.js
```

**실행 결과:**
```
✨ 데모 스페이스 생성 완료!

📍 스페이스 코드: DEMO01
📍 스페이스 이름: 영업용 데모 라운지
📍 조인 URL: /join/DEMO01

💡 조인 시 자동으로 부매니저 권한이 부여됩니다
```

### 2단계: 영업 대상자에게 링크 전달

**조인 링크:**
```
https://yourapp.com/join/DEMO01
```

또는 앱 내에서:
1. "방 가입하기" 선택
2. 코드 `DEMO01` 입력

### 3단계: 자동으로 부매니저 권한 획득

- 조인 즉시 **부매니저(vice-manager)** 권한 자동 부여
- 예약 생성/수정, 정산 관리 등 모든 기능 체험 가능

## ⚙️ 작동 원리

### 1. 데모 스페이스 플래그

`spaces/DEMO01` 문서에 `isDemoSpace: true` 플래그가 설정됩니다.

```javascript
{
  name: '영업용 데모 라운지',
  isDemoSpace: true,  // 👈 이 플래그가 핵심
  accountBank: '카카오뱅크',
  // ...
}
```

### 2. 자동 권한 부여 로직

`spaceService.js`의 `joinSpace()` 함수에서 자동으로 권한을 부여합니다:

```javascript
// 데모 스페이스 여부 확인
const isDemoSpace = space.isDemoSpace === true;
const autoUserType = isDemoSpace ? 'vice-manager' : 'guest';

// 사용자 추가 시 자동 권한 적용
userType: autoUserType  // 데모 스페이스면 vice-manager, 아니면 guest
```

## 🔧 문제 해결

### Q: 스크립트 실행 시 에러가 발생합니다
**A:** `.env` 파일에 Firebase 설정이 올바른지 확인하세요.

```bash
# .env 파일 확인
cat .env | grep VITE_FIREBASE
```

### Q: 조인해도 게스트 권한만 받습니다
**A:** `spaces/DEMO01` 문서에 `isDemoSpace: true` 필드가 있는지 확인하세요.

### Q: 데모 스페이스를 삭제하고 싶습니다
**A:** Firebase Console에서 `spaces/DEMO01` 문서를 수동으로 삭제하세요.
